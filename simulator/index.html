    Rencana perjalanan

    Modifikasi kendaraan

    Lalu lintas lajur kiri. Kemudi manual itu bebas: tahan ← / → untuk menyetir ke mana saja, termasuk bahu jalan, lajur lawan di jalan nasional, atau lajur yang ditutup. Tahan rem saat berhenti untuk mundur. Untuk keluar, setir ke kiri ke ramp saat papan EXIT terlihat (berlaku juga di simpang susun dan rest area); di jalan nasional, setir ke kiri di persimpangan untuk belok. Perjalanan berlanjut dari jalan yang Anda ambil. Mode Keliling bebas tidak punya tujuan: pilih arah di panel tiap simpang, atau buka Peta (M) untuk navigasi ke kota, gerbang tol atau simpang mana saja. Pelanggaran dan tabrakan tetap dicatat. Autopilot selalu mengikuti rute dan aturan: berhenti di gerbang tol dan lampu merah, patuh batas kecepatan, truk dan bus di lajur kiri.

    Mode pekerjaan

    Layanan

    Admin server

    PIN diperiksa oleh server. Admin bisa mengatur cuaca, jam, lalu lintas dan kondisi jalan untuk semua pemain.

    Kelola pemain

    Pemain (3 jam terakhir)
    Diblokir (ban aktif)

    Kick: keluar dari multiplayer (bisa masuk lagi setelah 3 menit). Ban: tidak bisa masuk dari IP dan perangkat itu sampai dibuka atau habis waktunya. Data IP dan perangkat hanya terlihat oleh admin.
